# Fullstack App Forge

Build an independent portfolio application inspired by yu-ai-code-mother. The platform and its generated full-stack applications use Next.js and FastAPI.

- Read `docs/spec.md` and `docs/plans/2026-10-01-full-rebuild.md` before implementing a phase. Pending product decisions block only their listed steps.
- Decision records (ADR) live in `docs/adr/`.
- Platform data and generated-application data must have separate ownership and credentials. Generated code must never execute inside the platform API process.
- Success requires the declared artifact checks and application health checks; model completion alone is insufficient.
- Preserve original authorship attribution for references. Do not copy reference code or assets without checking their license.
- Phase validation commands and their evidence boundaries live in the plan attachments. Do not report a primitive spike as a product or sandbox acceptance test.
